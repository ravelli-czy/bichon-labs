Introducción

StockFlow REST API

API pública para integrar tu sistema de inventario, pedidos, envíos y más con aplicaciones externas — ERP, ecommerce, automatizaciones o tu propio frontend.

Todas las rutas requieren autenticación mediante API Key + API Secret. Crea tus credenciales en Usuarios → API Keys.

Ejemplo rápido — Listar órdenes

cURL 
curl https://bichon-labs.vercel.app/api/v1/harmony/OMS/orders \
  -H "X-API-Key: sfk_a1b2c3d4e5f6..." \
  -H "X-API-Secret: 4f3a2b1c..."
Autenticación

API Keys

Cada solicitud debe incluir dos headers HTTP: el identificador público (X-API-Key) y el secreto (X-API-Secret).

HTTP Headers 
X-API-Key: sfk_a1b2c3d4e5f6a1b2c3d4e5f6
X-API-Secret: 4f3a2b1c0d9e8f7a6b5c4d3e2f1a0b9c
El API Secret se muestra una única vez al crearse. Guárdalo en un lugar seguro — no puede recuperarse. Si lo pierdes, revoca la key y crea una nueva.

Cómo crear API Keys

Las API Keys se crean por usuario, dentro de la sección Usuarios. Cada usuario puede tener hasta 10 keys activas. Las keys heredan los permisos del usuario (admin o staff).

Seguridad recomendada

• Nunca expongas el API Secret en código front-end o repos públicos.
• Usa variables de entorno o vaults para almacenarlos.
• Crea keys específicas por integración — así puedes revocar accesos individualmente.
• Revisa el campo last_used_at para detectar keys inactivas.

URL Base

Estructura de rutas

Todas las rutas de la API v1 incluyen el slug de tu cuenta (nombre abreviado del cliente), el microservicio y el recurso.

Base URL https://bichon-labs.vercel.app/api/v1/{account}/{microservicio}/{recurso}
SegmentoDescripciónEjemplo
{account}Slug de tu cuenta/tiendaharmony
{microservicio}OMS / WMS / SHM / IAMOMS
{recurso}Nombre del recursoorders

OMS — Order Management

Órdenes

Gestión completa de órdenes de venta: creación, consulta, actualización de estado y eliminación.

GET /api/v1/:account/OMS/orders Listar órdenes

Retorna todas las órdenes del tenant, ordenadas por fecha descendente.

Query params opcionales

ParámetroTipoDescripción
statusstringFiltrar por estado: pending · processing · done · cancelled

Respuesta

JSON Array
[
  {
    "id": "ORD-001",
    "cliente": "María González",
    "telefono": "+56 9 1234 5678",
    "total": 139000,
    "fecha": "2026-05-30",
    "status": "pending",
    "items": [{ "sku": "KIT-001", "qty": 1, "type": "kit" }],
    "delivery": { "method_type": "home_delivery" },
    "created_at": "2026-05-30T12:00:00Z"
  }
]
GET /api/v1/:account/OMS/orders/:id Obtener orden por ID

Retorna el detalle de una orden específica incluyendo estado del envío asociado.

cURL
curl https://bichon-labs.vercel.app/api/v1/harmony/OMS/orders/ORD-001 \
  -H "X-API-Key: sfk_..." \
  -H "X-API-Secret: ..."
POST /api/v1/:account/OMS/orders Crear orden

Crea una nueva orden y descuenta stock automáticamente. También crea el envío asociado si se especifica delivery.

Body (application/json)

CampoTipoReq.Descripción
clientestringreqNombre del cliente
telefonostringoptTeléfono de contacto
fechastringreqFecha en formato YYYY-MM-DD
itemsarrayreqArray de { sku, qty, type } (type: product | kit)
deliveryobjectoptObjeto de entrega (ver abajo)
dedicatoriastringoptMensaje dedicatoria
JSON Body
{
  "cliente": "María González",
  "telefono": "+56912345678",
  "fecha": "2026-05-30",
  "items": [
    { "sku": "KIT-001", "qty": 2, "type": "kit" },
    { "sku": "PRD-001", "qty": 1, "type": "product" }
  ],
  "delivery": {
    "method_type": "home_delivery",
    "address_street": "Av. Providencia 1234",
    "address_city": "Santiago"
  }
}
PUT /api/v1/:account/OMS/orders/:id Actualizar orden

Actualiza el estado u otros campos de una orden existente.

CampoTipoDescripción
statusstringpending · processing · done · cancelled
dedicatoriastringMensaje dedicatoria
DELETE /api/v1/:account/OMS/orders/:id Eliminar orden

Elimina la orden. El stock no se devuelve automáticamente.

WMS — Warehouse Management

Productos

Catálogo de productos con stock, precios y control de umbral de alerta.

GET /api/v1/:account/WMS/products Listar productos

Retorna todos los productos del tenant con su stock actual.

JSON Array
[
  {
    "sku": "PRD-001",
    "name": "Cámara IP 1080p",
    "brand": "Hikvision",
    "cat": "Seguridad",
    "tipo": "producto",
    "cost": 45000,
    "price": 79000,
    "stock": 24,
    "threshold": 10
  }
]
GET /api/v1/:account/WMS/products/:sku Obtener producto

Retorna el detalle de un producto por su SKU.

POST /api/v1/:account/WMS/products Crear producto
CampoTipoReq.Descripción
namestringreqNombre del producto
brandstringoptMarca
catstringoptCategoría
tipostringoptproducto · insumo · ambos
costintegeroptCosto unitario
priceintegeroptPrecio de venta
stockintegeroptStock inicial
thresholdintegeroptUmbral de alerta de stock bajo
PUT /api/v1/:account/WMS/products/:sku Actualizar producto

Actualiza nombre, precios, stock o threshold. Envía solo los campos a modificar.

DELETE /api/v1/:account/WMS/products/:sku Eliminar producto

Elimina el producto del catálogo. Solo disponible para admins.

KITs

Bundles compuestos por varios productos. Al vender un KIT, se descuenta el stock de cada componente.

GET /api/v1/:account/WMS/kits Listar KITs
JSON Array
[
  {
    "sku": "KIT-001",
    "name": "Kit Seguridad Básico",
    "price": 139000,
    "items": [
      { "sku": "PRD-001", "qty": 1 },
      { "sku": "PRD-002", "qty": 1 }
    ]
  }
]
Los mismos endpoints GET/:sku, POST, PUT, DELETE están disponibles en /WMS/kits/:sku con los mismos campos que productos.

IAM — Identity & Access

Usuarios y Logs

Consulta de usuarios del tenant y registro de actividad. Solo admins pueden acceder.

GET /api/v1/:account/IAM/users Listar usuarios

Retorna todos los usuarios del tenant con su rol y estado. Requiere API key de usuario admin.

GET /api/v1/:account/IAM/logs Audit logs

Registro de actividad del tenant. Soporta filtros y paginación.

ParámetroTipoDescripción
entity_typestringFiltrar por tipo: orden · producto · usuario · api_key
actorstringFiltrar por usuario que realizó la acción
limitintegerRegistros por página (default: 60, max: 500)
offsetintegerDesplazamiento para paginación
JSON
{
  "rows": [
    {
      "id": "LOG-001",
      "actor": "jperez",
      "action": "orden.creada",
      "entity_type": "orden",
      "entity_id": "ORD-042",
      "details": {},
      "created_at": "2026-05-30T12:00:00Z"
    }
  ],
  "total": 128,
  "limit": 60,
  "offset": 0
}
Errores

Códigos de respuesta

La API usa códigos HTTP estándar. Los errores incluyen siempre un campo error descriptivo.

200OK — Éxito
201Created — Recurso creado
400Bad Request — Datos inválidos
401Unauthorized — Sin credenciales
403Forbidden — Sin permisos
404Not Found — Recurso no existe
409Conflict — Ya existe (SKU duplicado)
500Server Error — Error interno
Error Response
{
  "error": "Stock insuficiente para PRD-001 (disponible: 2, requerido: 5)"
}
